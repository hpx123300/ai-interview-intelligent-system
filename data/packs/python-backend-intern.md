# Python 后端开发实习 · 面试问题包

## Round structure
1. 自我介绍与项目 walkthrough（10m）
2. Python 语言基础 + 数据库/网络/OS 八股（15m）
3. 场景设计与手写代码（10m）——接口设计、并发、SQL 优化
4. 行为面试（5m）——复盘能力、协作
5. 反问环节（5m）

## Question bank
- Python 的 GIL 是什么？IO 密集和 CPU 密集分别怎么选？
- 装饰器/生成器/闭包各解决什么问题？
- MySQL 索引为什么用 B+ 树？索引失效场景有哪些？
- 接口响应慢怎么排查？缓存三兄弟怎么应对？
- 进程/线程/协程的区别？IO 多路复用是什么？
- 手写一个 LRU 缓存 / 反转链表 / 二分查找？
- 你的项目表结构怎么设计的？为什么？

## Signals
- 基础题能给出结论 + 原理 + 例子，而不是背定义
- SQL/并发场景题有排查思路（分层定位、EXPLAIN）
- 手写代码前先讲思路、说复杂度

## Pitfalls
- 只会背八股，场景题没有思路
- 代码能写但讲不清复杂度与边界
- 数据库题只会"加索引"，说不清为什么失效
