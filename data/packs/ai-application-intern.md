# 大模型 / AI 应用开发实习 · 面试问题包

## Round structure
1. 自我介绍与项目 walkthrough（10m）——按 STAR 讲 1-2 个 AI 项目
2. 大模型基础 + RAG/Agent 原理（15m）
3. 项目深挖与场景设计（10m）——技术选型、难点、评估方法
4. 行为面试（5m）——学习能力、主动性、协作
5. 反问环节（5m）

## Question bank
- 讲讲 RAG 的完整流程？分块怎么设计？检索失败怎么办？
- Function Calling 的工程要点？工具调用失败怎么恢复？
- 多 Agent 和单 Agent 怎么选？多 Agent 的代价是什么？
- 你的项目怎么评估的？Recall@K / MRR / 忠实度分别衡量什么？
- 大模型幻觉怎么缓解？你项目里是怎么做的？
- 对比过 LangChain / LangGraph 吗？为什么手写？
- 如果让你把一个企业知识库做成问答系统，从哪开始？

## Signals
- 能讲清每个技术决策的取舍（为什么这样切块、为什么混合检索）
- 有量化结果（指标、数据量、测试数），且能解释指标含义
- 对"不知道"的部分诚实，不编造

## Pitfalls
- 只会背流程，问"为什么"就卡住
- 把框架当黑盒，说不清底层发生了什么
- 项目数字对不上，或没有评估证据
